# BeatLab — WordPress Project

BeatLab is a WordPress-based e-learning/course website built with WordPress, Astra and LearnPress.

## Technologies

- WordPress
- PHP
- MySQL / MariaDB
- Astra
- LearnPress
- Gutenberg / Ultimate Addons for Gutenberg
- Contact Form 7
- HTML / CSS / JavaScript

## Local setup

1. Install WordPress locally.
2. Create a database named `djcourse`.
3. Import the project database separately if you have permission to use it.
4. Copy `wp-config-sample.php` to `wp-config.php` and set your local credentials.
5. Place the project in your local web-server directory.

## Repository notes
